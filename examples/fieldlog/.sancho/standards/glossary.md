# Glossary

| Preferred term | Definition | Avoid | Code / UI |
|---|---|---|---|
| job | one visit of a technician to a site, with activity, duration, photos | ticket, intervention report | code `Job` · it "intervento" |
| site | the address where the job happens | location, place | code `Site` · it "impianto" |
| technician | field worker who logs jobs | operator, user (ambiguous) | code `Technician` · it "tecnico" |
| back-office | office staff using the dashboard | admin (it is a role, not a team) | it "ufficio" |
| sync | upload of locally saved jobs to the API | upload, push | code `SyncQueue` |
